# dtrpg-sdk.js documentation

`@pilgrimagesoftware/dtrpg-sdk` is a Node/TypeScript SDK for the
[DriveThruRPG API](https://api.drivethrurpg.com). It provides configuration,
authentication/session lifecycle, and an async library client for listing
orders, product lists, and preparing downloads. This is the latest
documentation.

## Getting started

- [Installation]({{ '/latest/install/' | relative_url }}) - install the
  package and its Node version requirement.
- [Quick start]({{ '/latest/quickstart/' | relative_url }}) - configure the
  SDK, authenticate, and make your first library request.

## Using the SDK

- [Authentication]({{ '/latest/authentication/' | relative_url }}) -
  application-key and credential-based login, and session lifecycle.
- [Library client]({{ '/latest/library-client/' | relative_url }}) - ordered
  products, product lists, and download preparation.
- [Errors]({{ '/latest/errors/' | relative_url }}) - the SDK's typed error
  hierarchy and how to handle each kind.
